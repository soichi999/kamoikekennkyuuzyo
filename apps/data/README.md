## 候補

### 1. 避難所データ（国土地理院）★本命

- **URL**: https://hinanmap.gsi.go.jp/hinanjocp/hinanbasho/koukaidate.html
- **内容**: 指定緊急避難場所・指定避難所の一覧。CSV形式で緯度経度・施設名・住所・災害種別フラグ付き。市町村別にダウンロード可能
- **項目**: NO, 共通ID, 都道府県名及び市町村名, 施設・場所名, 住所, 洪水/崖崩れ/高潮/地震/津波/大規模な火事/内水氾濫/火山現象 の各フラグ, 指定避難所との住所同一, 緯度, 経度, 備考
- **接続先**: `scoring` の `refuge` factor + `nearestRefuge()`
- **難易度**: 低。CSVをバンドル or R2/D1に投入するだけ。今日中に確実にできる

### 2. 犯罪データ（警視庁／東京都防犯ネットワーク）

- **URL**: https://www.bouhan.metro.tokyo.lg.jp/open-data/
- 警視庁ページ: https://www.keishicho.metro.tokyo.lg.jp/about_mpd/jokyo_tokei/jokyo/ninchikensu.html
- **種類**:
    - 「町丁字別犯罪情報」: 罪種別・手口別の認知件数、KEY_CODE（2010年国勢調査小地域コード）付。正確だが町丁字ポリゴンとの突合が必要でやや重い
    - 「犯罪発生情報 年計」: ひったくり・車上ねらい・自転車盗等の発生地点CSV（座標丸め済み）。直接距離計算可能。子供関連は「声かけ」「子供に対する犯罪」で件数少なめ
- **接続先**: `scoring` の `crime` factor
- **難易度**: 中。年計CSVなら座標ベースで直接使える

### 3. 未調査（時間があれば）

- 交通事故: 警察庁の事故原票は利用申請が必要で重い。都のオープンデータに代替がないか要確認
- 街灯・夜間照明: データがあるか未確認。無ければ mock のまま「今後の拡張」として説明

## 方針

1. 最優先: 避難所CSVを接続して `refuge` を実データ化
2. 余裕があれば犯罪年計CSVで `crime` を追加
3. traffic / lighting は mock のまま許容
