## やったこと

ポアソン回帰で危険度係数を推定した。**2つのモデルを推定**し、最初のモデルで逆符号が出たためモデルを修正した。

### モデル1（カウントベース・初版）

```
log(λ) = offset(log JINKO) + β1*koban_n + β2*school_n + β3*conveni_n + 区ダミー
```

### モデル2（距離ベース・修正版）

```
log(λ) = offset(log JINKO)
       + β1*log(dist_koban_m)
       + β2*log(dist_school_m)
       + β3*log(pop_density)
       + β4*log(conveni_density + 1)
       + 区ダミー
```

## 詰まった点と解決（プレゼン用に記録）

### 逆符号の発見

モデル1で交番・コンビニの係数が**正**（多いほど危険）と出た。これは「駆け込み先が多いほど安全」という仮説と逆。

### 原因の仮説と対処

交絡（都市化・人出）が原因と判断。都市化した地域は交番・コンビニが多く、同時に人出も多く事件も多い。そこで:

1. 交番・学校を「カウント」から「最寄りまでの距離」に変更
2. 都市化を `pop_density` で明示的にコントロール
3. コンビニを「密度」に変更

### 結果

モデル適合は改善（AIC -55）したが、**距離変数は依然として負**（近いほど事件が多い）。

これは逆因果ではなく、**「学校の近く = 子どもが集まる = 声かけ事案が集中する」**という構造を反映している可能性が高い。不審者・声かけは子どもが標的で、学校周辺は子どもがいる場所だから。

**「駆け込み先密度 = 安全」という仮説は、このデータでは支持されない。**

指示どおり変数は落とさず、符号も反転させず、そのまま報告する。
