# Phase 3 — 施設 → 町丁目に空間結合

- 作成者: tada246
- 使用AIモデル: deepseek/deepseek-v4-pro-0813
- タイムスタンプ: 2026-08-22

## やったこと

施設3種（交番・学校・コンビニ）をジオコーディングし、町丁目ポリゴンに 300m バッファで空間結合して集計表を作成した。

1. 交番・駐在所 688件 → 国土地理院API でジオコーディング
2. 学校 1,193件（4ファイル・23区）→ 国土地理院API でジオコーディング
3. コンビニ 5,880件 → OSM Overpass API で取得（座標付き）
4. 町丁目境界を (CITY_NAME, S_NAME) で dissolve（人口合算）
5. 各施設を 300m バッファ内でカウント
6. 事件データを町丁目単位に集計
7. 人口0の町丁目を除外

## 詰まった点と解決

1. **学校の区名補完**: 住所が町名始まり（`麹町2-8`）の行が大半。`設置者` 列（区立=区名）から区を補完。都立（設置者=「東京都」）は住所に区名があるため判定可能。結果、23区の学校 1,193件を漏れなく特定。
2. **町丁目境界の重複ポリゴン**: 同一 (CITY_NAME, S_NAME) が複数ポリゴンに分かれる。人口は1箇所にのみ入っている（他は0）ことを確認し、`dissolve` で合算が正しいことを検証（23区総人口 9,733,276 で整合）。
3. **コンビニの bbox**: 23区の正確な bbox を shapefile から算出（35.5209,139.5629,35.8175,139.9211）して取得。
