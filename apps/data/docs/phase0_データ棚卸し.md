## 詰まった点と解決

1. **学校CSVのエンコーディング**: UTF-8 で読むと `UnicodeDecodeError`。CP932 (Shift-JIS) で解決。
2. **住所に都道府県・区名が無い**: 全ファイル「東京都」始まり0件。`千代田区〜` と `麹町〜`（町名始まり）が混在。区名補完は `設置者` 列（高校は `所在地/区市町村` 列）から取得可能。設置者「東京都」の行は郵便番号フォールバックが必要（実質2件）。
3. **交番・学校・コンビニすべて緯度経度なし**: 住所テキストのみ。ジオコーディングが Phase 1 以降の最大作業。

## 次フェーズへの申し送り

1. 事件データを「不審者・声かけ事案」(2,677件) に絞り込む
2. 交番・学校・コンビニ → 住所からのジオコーディング（国土地理院API / OSM取り直し）
3. 町丁目境界 CRS (EPSG:2451) → ポイントデータと結合するため変換
4. JINKO=0 の町丁目 610件 → 分析から除外
5. 事件データ住所空白 2,174件 → 位置特定不可として除外
